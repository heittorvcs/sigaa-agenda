Política de Privacidade

Agenda SIGAA · última atualização: 13 de outubro de 2026

Esta política descreve como a extensão para Firefox Agenda SIGAA trata os seus dados. A extensão é um projeto pessoal e não oficial, sem vínculo com a UFRN nem com o Google.

Resumo

  • A extensão não tem servidor. Nenhum dado seu é enviado ao desenvolvedor.
  • Os dados acadêmicos vão do seu navegador direto para o seu Google Agenda, e para nenhum outro lugar.
  • Nada é vendido, compartilhado com terceiros nem usado para publicidade.

Dados que a extensão lê

OrigemO que é lidoPara quê
Portal do Discente do SIGAA (página aberta por você) Nome, local e horário das turmas do semestre; título, tipo, disciplina e prazo das atividades. Montar os eventos da agenda.
Google Agenda Somente os eventos criados pela própria extensão, identificados por uma marcação interna. Saber se uma atividade já está na agenda, para não criar duplicatas.

A extensão não lê sua senha do SIGAA, suas notas, seus dados pessoais do portal nem os outros eventos da sua agenda.

Dados enviados ao Google

Para cada atividade, a extensão cria ou atualiza um evento no Google Agenda da sua conta com título, disciplina, prazo, horário e local da turma. O envio é feito pela API do Google Agenda, com a permissão https://www.googleapis.com/auth/calendar.events, que você autoriza ao conectar a conta.

Dados guardados no seu computador

Ficam no armazenamento local da extensão no Firefox (browser.storage.local): as configurações, os tokens de acesso ao Google, a última leitura do portal e a lista de eventos já criados. Esses dados não saem do seu computador, exceto os tokens, que são enviados somente ao Google para autenticar as chamadas.

Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados do Google Agenda são usados somente para criar e atualizar os eventos das suas atividades. Eles não são transferidos a terceiros, usados para publicidade nem lidos por pessoas.

Como revogar o acesso e apagar os dados

  • No popup da extensão, clique em Desconectar: os tokens são apagados e o acesso é revogado no Google.
  • Você também pode revogar em myaccount.google.com/permissions.
  • Remover a extensão do Firefox apaga todos os dados guardados localmente.
  • Os eventos criados ficam na sua agenda até você apagá-los.

Alterações

Mudanças nesta política serão publicadas nesta página, com a data de atualização.
